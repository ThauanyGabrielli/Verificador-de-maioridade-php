🚀 Desafio 5A — Verificação de Acesso por Idade

Projeto desenvolvido em PHP como parte de uma atividade prática de programação.

📋 Sobre o projeto

O desafio consiste em criar um sistema simples que solicita o nome e o ano de nascimento do usuário, calcula sua idade e verifica se ele possui 18 anos ou mais para determinar se o acesso será permitido.

⚙️ Funcionalidades

📝 Formulário para informar o nome do usuário.

📅 Formulário para informar o ano de nascimento.

🧮 Cálculo automático da idade.

✅ Permissão de acesso para usuários maiores ou iguais a 18 anos.

❌ Negação de acesso para menores de idade.

📄 Registro dos acessos permitidos no arquivo log_acessos.txt.

💬 Mensagens exibidas

Para usuários com 18 anos ou mais:

Acesso permitido, [Nome]!


Para usuários menores de 18 anos:

Acesso negado, [Nome]!

🛠️ Tecnologias utilizadas

PHP

HTML

Manipulação de arquivos .txt

📁 Estrutura do projeto
.
├── 5a_desafio1.php
└── log_acessos.txt


O arquivo log_acessos.txt é criado automaticamente pelo sistema quando ocorre um acesso permitido.

▶️ Como executar
1. Clone o repositório
git clone URL_DO_SEU_REPOSITORIO

2. Acesse a pasta do projeto
cd nome-do-repositorio

3. Execute o projeto

Utilize um servidor local com suporte a PHP, como XAMPP, WAMP ou o servidor embutido do PHP.

Com o PHP instalado, também é possível executar:

Depois, acesse no navegador:

http://localhost:8000/5a_desafio1.php
